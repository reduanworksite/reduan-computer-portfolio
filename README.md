# Reduan Computer — Portfolio Website

Portfolio website for **Reduan Hossain** — Digital Marketer & Computer Educator.

**Live site:** https://reduanworksite.github.io/reduan-computer-portfolio/

## About

Reduan Computer is a minimal, modern, clean portfolio site:

- **Home / Hero** — who Reduan is and what he does
- **About Me** — digital marketing + computer education
- **My Skills** — SEO, Local SEO, Google Business Profile, Meta Ads, Microsoft Office, Organic Growth
- **My Services** — Local SEO, GBP optimisation, SEO & keyword research, Meta Ads, Office training
- **My Projects** — Reduan Computer, Reduan Digital, TerraNest (verified links only)
- **Contact** — email and Facebook pages

## Tech

- Pure HTML + CSS + JavaScript — no framework, no build step, fast loading
- Mobile-first, fully responsive
- Premium typography (Inter + Sora), navy / blue / gold palette
- Smooth scroll + reveal-on-scroll animations, respects `prefers-reduced-motion`

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Deploy

This repo is published with **GitHub Pages** from the `main` branch (root folder).
